# Guardian OS Updates

Repositório público exclusivo para artefatos de atualização assinados do Guardian OS.

- Não contém código-fonte privado, chaves ou credenciais.
- A rig aceita somente manifestos Ed25519 da chave confiável instalada localmente.
- Hash SHA-256, tamanho, canal e sequência anti-downgrade também são verificados.
- Pacotes ainda não liberados nunca são publicados aqui.

Os canais ficam em `gmos/stable`, `gmos/beta` e `gmos/canary`. Os bundles imutáveis ficam em `gmos/objects/sha256`.
